## Обзор

**«Питание и калории»** — premium-модуль RunBonus для контроля питания. Он объединяет:

- **Дневник питания** — запись съеденной еды с калориями и БЖУ
- **Связь с тренировками** — автоматический расчёт сожжённых калорий из GPS-пробежек
- **AI-диетолог** — распознавание блюда по фото (OpenAI Vision)
- **Аналитику и советы** — баланс за неделю/месяц, рекомендации по белку и активности

Модуль доступен только подписчикам **RunBonus+**. Без подписки пользователь видит paywall с описанием возможностей.

## Как пользоваться

### Шаг 1. Подключить RunBonus+

Подписка выдаётся администратором (**Админ → Питание → Выдать RunBonus+**) или через in-app purchase (в разработке).

В режиме разработки можно включить бесплатный доступ:

```env
NUTRITION_DEV_FREE=1
```

### Шаг 2. Открыть раздел питания

На экране **Сводка** нажмите карточку «Питание RunBonus+». Откроется экран с дневной статистикой.

### Шаг 3. Добавить еду

Нажмите кнопку **«Добавить еду»** внизу экрана. Доступны 4 способа:

| Способ | Когда использовать |
|--------|-------------------|
| **Фото (AI)** | Сфотографировать блюдо — AI определит название и БЖУ |
| **Поиск** | Найти продукт в базе (плов, борщ, курутоб и др.) |
| **Вручную** | Ввести название и калории самостоятельно |
| **Избранное** | Быстро добавить ранее сохранённые продукты |

Для каждой записи выбирается **приём пищи**: завтрак, обед, ужин или перекус.

### Шаг 4. Следить за балансом

Экран автоматически обновляет:

- сколько **съедено** и **сожжено** за день;
- сколько **осталось** до дневной цели;
- разбивку по **приёмам пищи** и **БЖУ**;
- **график за неделю** (съедено vs сожжено).

Потяните экран вниз для обновления данных (pull-to-refresh).

### Шаг 5. Удалить запись

В блоке **«История сегодня»** нажмите иконку корзины рядом с записью.

## Способы добавления еды

### 1. AI-фото (`PhotoAnalysisSheet`)

```
Пользователь → камера/галерея → сжатие фото → POST /api/nutrition/photo
    → OpenAI Vision (или fallback из базы) → результат с confidence
    → пользователь редактирует → POST /api/nutrition (source: photo_ai)
```

- Фото сохраняется на сервере в `uploads/nutrition-photos/`
- Максимальный размер: **6 МБ**
- Форматы: JPEG, PNG, WebP
- Если **confidence < 80%** — предлагаются альтернативные блюда
- Пользователь может изменить название, граммы, калории и приём пищи перед сохранением

### 2. Поиск по базе (`AddFoodSheet` → search)

```
Ввод текста → GET /api/nutrition/foods/search?q=... → выбор продукта
    → POST /api/nutrition (source: search, food_id: ...)
```

Калории и БЖУ пересчитываются автоматически по весу порции из справочника `nutrition_foods`.

### 3. Ручной ввод (`AddFoodSheet` → manual)

Пользователь вводит название, граммы, калории и (опционально) БЖУ.  
Запись сохраняется с `source: manual`.

### 4. Избранное (`AddFoodSheet` → favorites)

```
GET /api/nutrition/favorites → выбор → POST /api/nutrition (source: favorite)
```

Добавить в избранное можно из результатов поиска (`POST /api/nutrition/favorites/:foodId`).

## Как считаются калории

### Дневная цель (TDEE)

Цель рассчитывается из профиля питания (`user_nutrition_profile`):

1. **BMR** (базовый обмен) — формула Mifflin-St Jeor:
   - Мужчины: `10×вес + 6.25×рост − 5×возраст + 5`
   - Женщины: `10×вес + 6.25×рост − 5×возраст − 161`

2. **TDEE** = BMR × коэффициент активности:
   | Уровень | Коэффициент |
   |---------|-------------|
   | sedentary | 1.2 |
   | light | 1.375 |
   | moderate | 1.55 |
   | active | 1.725 |
   | very_active | 1.9 |

3. **Коррекция по цели**:
   - `lose` (похудение): −400 kcal
   - `gain` (набор): +300 kcal
   - `maintain`: без изменений

4. **Минимум**: 1200 kcal/день

### Цели по БЖУ

От дневной нормы калорий:

| Макронутриент | Доля | Формула |
|---------------|------|---------|
| Белки | 25% | `(ккал × 0.25) / 4` |
| Жиры | 30% | `(ккал × 0.30) / 9` |
| Углеводы | 45% | `(ккал × 0.45) / 4` |

### Сожжённые калории (из тренировок)

Берутся данные из таблицы `workouts` за текущий день:

```
estimateCalories(дистанция_км, активные_минуты, шаги, вес_кг)
```

Формула (берётся максимум из трёх компонентов):

- от дистанции: `км × вес × 0.9`
- от времени: `минуты × вес × 0.08`
- от шагов: `шаги × вес × 0.0004`

### Основные показатели дня

| Показатель | Формула | Описание |
|------------|---------|----------|
| **Съедено** | SUM(calories) из `nutrition_logs` за сегодня | Все записи дневника |
| **Сожжено** | estimateCalories из тренировок за сегодня | Связь с GPS-модулем |
| **Осталось** | `daily_goal − consumed` | Может быть отрицательным (превышение) |
| **Баланс** | `consumed − burned` | Положительный = профицит калорий |
| **Прогресс цели** | `(consumed / daily_goal) × 100%` | Отображается в кольце и полоске |

### Streak (серия дней)

При каждой новой записи обновляется `nutrition_diary_streaks`:

- Если запись в тот же день — streak не меняется
- Если на следующий день — `current_streak + 1`
- Если пропущен день — streak сбрасывается в 1
- При **7 дней подряд** — push-уведомление о milestone

## Рекомендации и уведомления

### AI-рекомендации (`GET /api/nutrition/recommendations`)

| Условие | Совет |
|---------|-------|
| Превышена дневная норма | «Превышена норма на X kcal. Пробежите ещё Y км» |
| Белка < 70% от цели | «Добавьте курицу, рыбу или яйца» |
| Цель = похудение, баланс > 500 | «Сократите потребление на 300–400 kcal» |

Расчёт «сколько км пробежать»:

```
kmToBurnCalories(избыток_ккал, вес) = избыток / (вес × 0.9)
```

### Push-уведомления

Отправляются автоматически при добавлении записи:

| Событие | Текст |
|---------|-------|
| Достигнута норма | «Вы достигли дневной нормы X kcal» |
| Превышение нормы | «Вы превысили дневную норму на X kcal» |
| До цели ≤200 kcal | «До цели осталось X kcal» |
| Streak 7 дней | «7 дней подряд ведёте дневник питания!» |

## AI-распознавание еды

### Алгоритм

```
1. Пользователь загружает фото (камера / галерея)
2. Backend сохраняет фото на диск
3. Если задан OPENAI_API_KEY → запрос к OpenAI Vision (gpt-4o-mini)
4. Если AI недоступен → fallback: 4 случайных блюда из базы (TJ/UZ/RU)
5. Результат сопоставляется со справочником nutrition_foods
6. Если confidence < 80% → флаг low_confidence + список alternatives
7. Пользователь редактирует и подтверждает → запись в nutrition_logs
```

### Переменные окружения

```env
OPENAI_API_KEY=sk-...
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_VISION_MODEL=gpt-4o-mini
NUTRITION_DEV_FREE=1          # dev: доступ без подписки
```

### Национальная кухня (seed-данные)

| Страна | Примеры блюд |
|--------|-------------|
| Таджикистан (TJ) | плов, курутоб, шашлык, манту, самбуса, шурбо, оши бурида |
| Россия (RU) | борщ, пельмени, блины |
| Узбекистан (UZ) | плов, лагман |
